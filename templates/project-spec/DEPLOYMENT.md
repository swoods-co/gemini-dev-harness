# Deployment & Environment Specifications

This document tracks deployment configurations, Netlify targets, and environment variables across environments.

---

## 1. Hosting & Infrastructure Target
- **Platform**: Netlify
- **Netlify Site Name**: [e.g., `my-frontend-project`]
- **Netlify Site ID**: [UUID from Netlify site dashboard or API]
- **Production Domain**: [e.g., `app.mycompany.com` or `my-frontend-project.netlify.app`]
- **Deploy Preview Subdomains**: Auto-generated by Netlify per pull request (`deploy-preview-<pr-number>--<site-name>.netlify.app`)

---

## 2. Build Settings (`netlify.toml` Alignment)
- **Base Directory**: `/`
- **Build Command**: `pnpm build` (or `npm run build`)
- **Publish Directory**: `dist` (Vite) or `.next` (Next.js) or `dist` (Astro)
- **Functions Directory**: (if using Netlify serverless functions) `netlify/functions`

---

## 3. Environment Variables & Secrets Manifest
> [!CAUTION]
> Never commit real values or tokens to this file or version control. Store secrets in Netlify Environment Variables or GitHub Actions Secrets.

| Variable Name | Environment(s) | Purpose | Required / Optional |
| :--- | :--- | :--- | :--- |
| `VITE_API_BASE_URL` | Dev, Preview, Prod | Base URL for REST/GraphQL endpoints | Required |
| `VITE_AUTH_DOMAIN` | Dev, Preview, Prod | Identity provider auth domain | Required |
| `VITE_ANALYTICS_ID` | Prod | Analytics telemetry tracking ID | Optional (Prod only) |

---

## 4. Release Checklist
- [ ] All unit, typecheck, and lint suites passing in CI (`ci.yml`).
- [ ] Deploy preview verified visually on mobile and desktop via Netlify MCP.
- [ ] Lighthouse score meets performance constraints (Performance ≥ 90, Accessibility ≥ 95).
- [ ] Secrets provisioned in Netlify production dashboard.
- [ ] PR approved and merged into `main`.
- [ ] Post-deploy production health check passes.
